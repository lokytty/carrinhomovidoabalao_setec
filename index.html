Fundamentação Teórica

Como a Física Faz o Carrinho Andar?

Análise dos conceitos de mecânica, gravidade, atrito e termodinâmica aplicados neste projeto experimental.

3ª Lei de Newton (Ação e Reação)

A toda ação corresponde uma reação de mesma intensidade e direção, mas de sentido oposto.

Ação: Ar expulso para trás
Reação: Carrinho impulsionado para a frente

Conservação de Energia

A energia potencial elástica armazenada no látex deformado da bexiga é convertida em energia cinética (movimento).

Epe = (k · x²) / 2 ➔ Ec = (m · v²) / 2

Forças de Atrito e Resistência

O atrito nos eixos das rodas e a resistência do ar limitam o alcance do carrinho. Reduzir o peso e alinhar eixos otimiza a distância.

Fat = μ · N (Reduzir atrito nos eixos)

Guia Prático

Materiais & Passo a Passo

Instruções para replicar o projeto da SETEC na sua escola ou feira de ciências.

Lista de Materiais Recicláveis

1

Montagem dos Eixos

Cole os dois canudos guia na parte inferior da garrafa PET de forma paralela. Passe os palitos de churrasco por dentro dos canudos.

2

Fixação das Rodas

Faça furos centrais nas 4 tampinhas e encaixe-as nas pontas dos palitos. Fixe com cola quente para evitar que deslizem em falso.

3

Sistema de Propulsão

Prenda o balão no canudo com uma liga de borracha ou fita isolante, garantindo vedação total sem amassar o canudo.

4

Fixação no Chassi

Fixe o canudo na parte superior do carrinho com a ponta direcionada para trás, garantindo empuxo em linha reta.

Como Colocar Este Site no GitHub Pages

Passo 1: Criar Repositório

Acesse o GitHub, crie uma conta (se não tiver) e clique em New Repository. Nomeie como carrinho-balao-setec.

Passo 2: Criar o arquivo `index.html`

Dentro do repositório no GitHub, clique em Add file ➔ Create new file, nomeie o arquivo exatamente como index.html e cole o código deste projeto.

Passo 3: Ativar o GitHub Pages

Vá em Settings ➔ Pages (no menu lateral do seu repositório). Em Build and deployment / Branch, selecione main e clique em Save.

Passo 4: Seu Site está no Ar!

Aguarde ~1 minuto. O GitHub gerará um link público como:
https://seu-usuario.github.io/carrinho-balao-setec/
